## 📘 Inleiding

In dit project maken we deel uit van het PingFin workshop, waarin we een vereenvoudigd SEPA-betaalsysteem simuleren. Als netwerkteam zijn wij verantwoordelijk voor het opzetten en beheren van de infrastructuur, zodat alle banken veilig en efficiënt met elkaar kunnen communiceren via het netwerk.
